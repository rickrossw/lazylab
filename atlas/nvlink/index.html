NVLink

Read it in Chapter 1 · checkpoint +50 XP →

NVIDIA's high-bandwidth GPU-to-GPU link: ~450 GB/s per direction per H100, roughly 7× PCIe Gen5.

NVLink is a point-to-point interconnect between GPUs. An H100 SXM has 18 NVLink 4 links totalling ~900 GB/s bidirectional (~450 GB/s each way). Through NVSwitch, all 8 GPUs in an HGX server talk to each other at full speed.

Design rule: put the chattiest parallelism on the fastest link. Tensor parallelism does several all-reduces per layer, so it lives inside the NVLink domain. Data parallelism, which syncs once per step and overlaps with compute, can cross InfiniBand & RoCE.

Failure mode: NVLink errors appear as Xid 74. A degraded link forces traffic over PCIe and quietly slows collectives. nvidia-smi nvlink -s shows per-link status, and all_reduce_perf (nccl-tests) on an idle node shows the bandwidth drop.
